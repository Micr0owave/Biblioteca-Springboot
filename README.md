por ende es lo mas sencillo para esta pequeña evaluacion sobre el uso de github

la rama main o master fue usada para mantener todo lo que queria que fuera implementado 

se creo la rama hotfix para hacer cambios rapidos de algun error
se creo la rama feature para agregar pequeñas cosas funcionales o de vista bonita
se creo la rama develop para estar desarrollando activamente 
se creo la rama main porque asi lo pide la evaluacion
